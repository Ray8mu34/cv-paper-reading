# CV 证据阅读示例：从分数提升到模块贡献

这份合成教学材料讨论一个常见的 CV 阅读问题：新模块的配置分数更高时，究竟能得到多强的结论？最初比较从 80% 到 82%，同时改变了预训练和训练安排；匹配关键条件后，差值只有 0.2 个百分点。先区分整套配置的表现与模块归因，再解释匹配对照、机制与统计判断如何连接。

## 为什么要先分清“配置表现”和“模块贡献”？

一个模块的设计目标可能是让特征交换更多有用信息，但准确率表格首先测量的是整套训练和推断配置。方法解释回答“改变了什么”，实验解释回答“这个改变在哪些条件下与结果有关”。二者需要通过合适的对照连接，而不是看到分数更高就跳到机制结论。

## 比较时真正被改变了哪些条件？

先把四个配置放在一起看。

|配置|训练数据|epochs|分辨率|Top-1 (%)|
|---|---|---|---|---|
|Base|目标数据|100|224|80.0|
|X|目标+外部预训练|300|224|82.0|
|Base matched|目标+外部预训练|300|224|81.8|
|X large|目标+外部预训练|300|384|83.0|

*固定的合成教学数值；不是实际训练结果。*

X 相比最初 Base 增加了外部预训练，并使用更长的训练安排。因此两行的 2 个百分点差异描述整套配置的变化，同时改变的因素阻止了直接把全部差值归给模块。Base matched 把关键数据和训练条件对齐后，提供了更贴近模块归因的问题。

## 匹配对照究竟提供了多少信息？

X 与 Base matched 的差值是 82.0−81.8=0.2 个百分点。它支持的是：在这组给定条件和固定结果中，使用 X 的配置取得略高的数值。X 增加容量，仍存在“更多容量”这一替代解释；要检验独特交互机制，可比较容量和预算匹配的替代路径。

每行只有一个值，无法从中估计训练种子波动或每样本配对差异；这不等于差异必然是噪声，也不等于统计显著。X large 再提高分辨率后达到 83.0%，说明又改变了一个条件，而不是自动给 X 增加一项独立机制证据。

## 百分点、相对准确率与相对错误率

同一个变化可以有三种表达。由 80% 到 82%，绝对差是 2 个百分点；相对准确率增加是 $2/80=2.5\%$；错误率从 20% 到 18%，相对错误率减少是 $2/20=10\%$。

这三者都能计算，但分母不同。解释指标时明确采用哪一种，才能避免把一个幅度讲成另一个幅度。

## 把解释停在证据能达到的位置

材料没有跨域、未见类别或部署结果，因而这些比较没有提供相应能力的证据。外部预训练的测试集重叠未知，应保留这一解释条件；未知本身不是已经证明的泄漏。

若研究问题就是 X 的独特机制，最有价值的下一步是匹配容量的替代路径和针对信息交换的干预；若问题是实际使用效果，则整套配置的质量与成本更直接。选择证据取决于问题。

## 进一步阅读：怎样提出有区分力的检验

重复种子回答固定流程的训练稳定性；同测试样本的预测可支持配对分析；容量匹配的替代路径检验收益是否来自独特机制；跨域协议检验另一类泛化。这些实验各自回答不同问题，不能互相充当替代，也不必全部塞进每一篇论文。
