## CV 专用适配

新增内容选择、实验/证据和任务约定。论文类型转为方法/表征、数据/基准、理论、系统和几何混合；科学完整性、统计、溯源、文章规则与质量检查改用 CV 对象和条件。保留先全局后局部、原文 § 地图、自然叙事、可见的关键推导、独立工作记录和按增益选择图形。

比较协议与证据条件使用现有 claims/assumptions/parameters/internal sections，无新的 schema 或强制 metadata 表。统计规范区分运行、样本和选择的波动；效率规范区分 FLOPs 与实测成本；可视化规范优先原证据，避免把热图/生成案例升级为机制证明。

## 验证层级

软件回归运行继承的测试；实现继承通过基线 commit 的文件内容比较核对。CV 合成材料用于检查四模式构建、正文/记录隔离、地图、离线 MathML 与页面。CV 决策规则通过具体反例审读，记录在 validation。

没有将合成材料称作真实论文，也没有将作者自查称作独立 Agent 评估；真实 CV 论文试读可另按实际需求执行。记录保存在本地，不进入阅读正文。
