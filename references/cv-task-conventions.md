# CV 任务约定卡：按论文实际任务选读

这些约定用于找出影响结论的条件，不是每篇论文都需展开的百科或检查清单。未知定义优先查原论文、数据集官方评估与作者实现，并保存版本。

|论文任务|先明确的对象与条件|会影响关键结论的区别|
|---|---|---|
|分类/表征/自监督|标签来源，预训练，特征提取层，probe 的训练与选择|linear probe / kNN / 全量微调不同；“冻结”对象、训练/测试增强、类均衡与宏/微平均|
|检测/实例分割/关键点|预测对象、坐标、候选与匹配、split、官方 evaluator|AP 阈值和面积范围、bbox/mask、crowd/ignore、最大检测数；关键点误差和尺度/可见性|
|语义/全景分割|标签空间、void/ignore、图像与像素聚合|mIoU / pixel accuracy / PQ 各测什么；小类、长尾、分辨率和测试裁剪|
|跟踪/视频|帧、片段和序列的输入范围，是否在线，身份与关联|主体/视频相关性、split 重叠、检测与关联指标、未来帧是否可用|
|生成/编辑/恢复|条件输入、目标分布、采样与参考、编辑约束|保真/多样性/遵循指令不同；FID 特征与样本数、paired/unpaired、PSNR/SSIM 范围、人类评估、best-of-N|
|视觉语言/开放词汇|图像/文本训练信息、候选标签、prompt、检索或上下文|zero-shot 定义、未见类相对于什么、文本监督/教师、额外模型和评判偏差|
|三维/几何/重建|相机模型、内外参、坐标系、尺度、视角与几何真值|单目尺度歧义、已知/估计 pose、seen/novel view、对齐方式、渲染指标与真实几何误差|
|效率/部署|目标设备、输入规模、测量范围和质量约束|训练/推断，单样本延迟/批量吞吐、batch、精度、缓存和后处理|

## 分类与表征

线性探针解释特征的可读出性，微调解释一套适配流程的效果，不能混写成同一“表征质量”。类别未见、实例未见和分布未见分别说明；预训练与下游监督要连成信息流。类别数量变化时，准确率基线和任务难度也可能变化。

## 密集预测

坐标归一化、裁剪/缩放、padding、标签 ignore、阈值与匹配影响结果解释；它们若不决定中心贡献，保存配置而不铺正文。COCO 等具体 AP 定义查 [官方评估实现](sources.md)，不用名称猜测协议。类别或面积分组结果可定位改善发生在哪里，不能用整体均值替代小目标或稀有类结论。

## 生成与恢复

先分清任务要保真、感知质量、多样性还是满足条件，指标只解释其所测方面。推断步数、引导强度、采样温度、候选挑选与额外模型可能改变质量—成本权衡。对同一输入的局部放大和失败样本有解释价值；不同随机样本的“前后滑块”容易给出错误的改善直觉。生成评判器自身的训练数据与偏差也是条件。

## 几何与三维

图像重建好不自动意味着几何正确，已知 pose 的新视角合成与估计 pose 的重建难度不同。坐标系、投影模型、尺度/对齐和遮挡关系若是中心机制，应充分推导，并区分训练视角插值与外推。射线/相机交互只有帮助解释可观测性或投影歧义时才制作。

## 不扩充 schema 的类型映射

经验方法用 paper.kind=method，理论用 theory，数据/诊断可用 observation 或 mixed，模拟研究用 simulation；这些是继承框架的粗路由。CV 子任务和贡献类型写在概览、内部约定卡与相关 sections 中。不要把 schema 中的粗类型当作读者章节模板。
