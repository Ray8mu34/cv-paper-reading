# CV Paper Reading

Use cv-paper-reading for graduate-level explanations of computer vision papers. Orient an unfamiliar reader first: research problem, actual bottleneck, contribution, results and scope, and the argument role of each original numbered section. Then explore consequential mechanisms in dependency order.

Select content using cv-content-selection.md and assess empirical claims using cv-evidence.md. Match evidence to the contribution: architecture, objective, data, theory, benchmark or system. Distinguish performance under a protocol from attribution to a mechanism; inspect supervision, pretraining, capacity, budget, inference and evaluation when relevant. Ablation, attention maps, generalization and efficiency each support different conclusions.

Use inherited schema 1.1 and the deterministic report pipeline. Keep sources, execution and evidence ledgers in analysis-notes.md; retain scientific conditions in the argument. Prefer original figures, and use interaction only for a specific explanatory gain. The retained astro_xray package and lensing fixtures are compatibility resources, not CV reading requirements.
