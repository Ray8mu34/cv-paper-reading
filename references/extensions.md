# 扩展 CV 子任务，保留共同框架

新任务卡描述输入/输出、监督来源、训练/推断信息、关键约定、中心难点、适用指标与主要误判。将其加入 cv-task-conventions 或独立参考文档，并在主入口按需加载；不复制阅读框架、改证据分类或另建 schema。

成像/逆问题关注前向模型、噪声、可辨识性与正则化；医学视觉关注患者/机构划分、标签与目标用途；遥感关注空间/时间划分与地理分布；机器人视觉关注传感器、坐标、时序和实际部署目标。这些是路由提示，不是现成求解器或已验证领域能力。

仅在现有原图、文字与 manifest 无法满足中心理解时开发组件。组件需有对应方程/算法/数据、计算域、必要单位与参考系、可检查的标准或解析输入，遵守既有图形契约。新图登记为本地资产，不将论文未知脚本直接执行。

一次示例中的问题不自动升为全局规则。真实论文阅读、方法论质量和软件回归分别评估，改动要有相应证据并保留旧框架回归。
