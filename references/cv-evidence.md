# CV 证据分析：从实验结果到论断之间的条件

## 主张先于检查表

先提炼作者希望读者相信的中心主张，再定位最直接的证据与必要对照：方法提高了性能？某组件产生某机制？表征可迁移？新数据更有价值？系统更快？一个定理成立？不同主张需要不同证据，不能只看谁的数字最大。

内部用现有 claims.evidence、claims.assumptions、parameters 与 internal section 记录“主张—原文位置—条件—支持层级—替代解释—剩余未知”。不扩展 schema，不要求所有论文填满同一张表。正文只保留理解结论必需的分析。

## 比较结果的协议

判断两个数可否直接比较时，按主张核对下列条件；能定位就记录，不能定位就标 unknown，避免补造。

|条件|可能改变哪种解释|
|---|---|
|数据、split、过滤、标签及类别定义|测试对象和监督信息是否相同；是否使用额外数据|
|预训练模型与数据、教师、伪标签|收益能否归于新方法；外部监督从何进入|
|backbone、容量、输入分辨率/token 数|表示能力、细粒度信息和计算预算是否改变|
|训练步数、epoch、batch、调参预算、recipe|同 epoch 未必同计算或样本暴露量；基线是否充分优化|
|推断增强、ensemble、候选数、迭代步数、检索库|报告的是单模型、完整系统还是更大测试预算|
|指标版本、评估代码、阈值与聚合|分数是否在测同一对象，能否横向比较|

条件一致不是判断贡献的唯一方式。不同配置的结果可以支持“这个系统在这些条件下达到此表现”；将差异归因于单个新机制，则需隔离其余关键变化。可按论文已有信息分组比较，保留原始结果与条件；不凭估计把不同 recipe 的数字“校正”到同一预算。

比较对象也包括更简单方法、既有机制、较强基线或作者选择的替代方案。是否缺少一个对照应由其能区分哪种解释来判断，不能笼统要求“更多 baseline”。历史论文中的 SOTA 只针对当时已明确的任务和协议；不写成未经核查的今天排名。

## 消融与因果解释

删除一个模块后性能下降，直接支持的是“这一实现与训练条件下，移除该模块会影响结果”。它不单独证明模块的独特机制、普遍必要性或其他方法无法替代。

看修改是否同时改变容量、梯度尺度、训练稳定性、数据暴露或预算；是否重新训练、重新调参，还是只在推断时关闭；后者可引入分布失配。单因素对照、匹配容量/预算的替代实现、组件交互和针对机制的干预各有不同作用，按中心主张选择讨论。

多组件不是可加的分数贡献。A+B 的改善不自动等于 A 与 B 的独立效应；没有全因子实验时不虚构交互结论。无消融不自动否定理论、数据集或系统论文，应找它们实际需要的证据。

## 机制证据与定性展示

注意力热图、特征投影、激活可视化、检索样本和生成图像可以揭示模式或提出假设，但其外观不直接证明因果重要性、对象理解或普遍语义能力。检查选例、色标、归一化、遮挡方式和比较样本；诊断或干预若改变模型行为，说明它具体排除了哪个替代解释。

几个漂亮案例解释能力的形态，完整评估才说明频率或覆盖范围。失败案例要与任务条件连接，如细小目标、遮挡、长尾、复杂纹理或域变化，不写成泛泛“仍有限制”。没有失败案例也不能反推作者隐瞒失败。

## 泛化、监督与污染

同分布测试、跨数据集迁移、跨域、腐败鲁棒性、未见类别和组合泛化分别判断，保留各自训练及测试信息。linear probe、全量微调、few-shot 和 zero-shot 回答不同问题，任务约定见 [CV 任务卡](cv-task-conventions.md)。

“下游零标注”不等于“从未见过相关图像、文本或概念”。视觉语言与基础模型比较要核对预训练、prompt/template、候选标签、教师、检索或 test-time adaptation；只将实际提供的信息写成事实。

同一视频/主体/场景的相关样本、重复图像和跨 split 重叠可造成独立性问题；公开测试反馈、标签参与调参也影响评估。把已证实的重叠、存在接触途径和完全未知分开。未知预训练数据是解释条件，不是已经证实泄漏。若数据治理本身不是主线，细节留内部，正文只讲会改变核心结论的风险与证据。

## 指标、稳定性与效率

指标定义、方向、尺度、样本单元和聚合必须清楚。不要混合 AP/AP50、bbox/mask AP、macro/micro、类别均值/像素汇总或不同生成评估配置。数字比较保留百分点和相对变化的区别；种子、样本波动、统计判断遵循 [评估与不确定性](statistics.md)。

参数、FLOPs/MACs、显存、延迟、吞吐、训练时间和总成本不能互作替代。比较实际运行需同硬件/软件、精度、batch、输入、同步/预热与测量范围；报告预训练、检索、后处理或解码是否计入。计算更少而延迟更高可以同时成立，解释瓶颈而非强行给单一排名。

## 将结论写在正确层级

区分作者报告的结果（R）、从数值独立得到的差值（D）、受条件支持的解释（I）与未检验机制（S）。优化目标、实验现象和方法成因之间保持推理链。正文自然说明改变结论的条件，例如额外预训练使主表无法独立隔离架构贡献；“本次未跑训练”属于工作记录。

审查要提出有区分力的问题：“匹配训练预算的替代模块能否保留收益？”比“缺少更多实验”更具体。若无法执行，把它写成候选检验，并保留原文能支持的结论。
