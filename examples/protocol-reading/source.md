# 对照条件与模块归因：合成教学材料

这是用于阅读管线与证据解释检查的合成材料，不是真实论文或模型实验。

## §1 问题
一个图像分类模块 X 希望提高准确率。需要区分整套配置的结果与 X 的独立贡献。

## §2 方法与信息
X 在既有 backbone S 上新增特征交互路径。架构细节未定义；这里仅讨论证据与比较协议。

## §3 结果
所有行使用同一个测试 split 和 top-1 指标。数字为固定教学值。

|配置|训练数据|epochs|分辨率|Top-1 (%)|
|---|---|---|---|---|
|Base|目标数据|100|224|80.0|
|X|目标+外部预训练|300|224|82.0|
|Base matched|目标+外部预训练|300|224|81.8|
|X large|目标+外部预训练|300|384|83.0|

Base matched 与 X 的 backbone、数据、训练步数/安排和评估配置一致，唯一区别是 X 路径；各行只给一个固定值，无重复运行、每样本预测或置信区间。X 路径改变容量，实际训练 FLOPs 和容量匹配替代实验未提供。没有跨域或未见类结果。外部预训练与测试集的重叠情况未给出。
